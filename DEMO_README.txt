레몬 | 더 코지 플로리스트 - v13 데모 빌드

[중요]
이 빌드는 운영 v13과 D1 저장 공간을 분리합니다.
- 운영 상태 ID: main
- 데모 상태 ID: demo
- 브라우저 localStorage도 demo_ 접두어를 사용해 운영 데이터와 분리됩니다.

[최초 실행]
D1에 demo 상태가 없으면 운영(main) 상태를 1회 복제하여 데모를 시작합니다.
그 뒤 데모에서 체크/추가/수정/삭제한 내용은 demo 상태에만 저장됩니다.
운영(main) 데이터에는 반영되지 않습니다.

[권장 배포]
기존 lemon-cozybook 운영 프로젝트를 덮어쓰지 말고 별도 Cloudflare Pages 프로젝트(예: lemon-cozybook-demo)로 배포하세요.
새 데모 프로젝트에도 D1 binding 이름 DB를 기존 lemon-cozybook-db에 연결해야 합니다.

[데모에서 공유되는 항목]
- 길드원 목록
- 꽃 체크/해제
- 등급별 닉네임 체크수
- 신규 꽃 추가/수정/삭제
- 업데이트 내역

[동기화]
기존 v13과 동일하게 D1을 통해 브라우저/기기 간 공유됩니다.
