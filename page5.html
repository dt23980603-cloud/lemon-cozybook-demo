🌷 전체 꽃 도감 사용 가이드 🌷

① 체크 대상 길드원 선택
상단의 👤 체크 대상 길드원에서 자신의 닉네임을 선택해주세요. 선택한 길드원의 보유 체크 상태가 각 꽃 카드에 표시됩니다.
② 꽃 보유 체크 / 해제
꽃 카드의 ✓ 보유 / □ 보유 버튼으로 선택한 길드원의 보유 여부를 바로 변경할 수 있습니다. 체크 내용은 길드 공용 데이터로 저장됩니다.
③ 보유한 꽃만 빠르게 보기
길드원을 선택하면 ✓ 보유만과 □ 미보유만 버튼이 나타납니다. 같은 버튼을 한 번 더 누르면 필터가 해제되어 전체 꽃이 다시 표시됩니다.
④ 등급별 보유 수 확인
길드원을 선택한 상태에서 N / R / SR / SSR / UR 등급을 누르면 현재 등급의 보유 꽃 수 / 전체 꽃 수를 바로 확인할 수 있습니다.
⑤ 길드 전체 보유 현황 확인
각 꽃 카드의 👥 길드 보유 현황에는 현재 그 꽃을 보유한 길드원이 표시됩니다. 인원이 많으면 더보기를 눌러 전체 명단을 펼칠 수 있습니다.
⑥ 꽃 검색과 상세 정보
꽃 이름 검색과 등급 필터를 함께 사용할 수 있습니다. 정보 보기에서는 분류, 길드전 점수, 획득 방법, 비고를 확인할 수 있습니다.
⑦ 길드원 정보 관리
상단의 ⚙️ 길드원 관리에서 길드원 추가, 직위·닉네임 수정, 삭제를 할 수 있습니다.
⚠️ 보유 체크는 길드원 모두에게 공유됩니다. 꽃을 체크하기 전에 선택된 닉네임이 맞는지 확인해주세요. 잘못 체크했다면 같은 꽃의 보유 버튼을 다시 눌러 해제하면 됩니다.
